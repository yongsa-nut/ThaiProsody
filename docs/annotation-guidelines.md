# Annotation Guidelines (คู่มือผู้ประเมิน)

**Thai Prosody benchmark · calibration annotation**

This is the instruction sheet given to the annotator, reproduced as used. It is written
for one or more annotators; the labels released with the benchmark come from one expert
(`thaiwrite/prosody/calibration/labels/labels_expertA.json`).

For expert annotators. Read this once, then label your file **independently** (if
more than one annotator takes part, do not confer during the independent pass: that is
what agreement is measured on).

---

## 1. งานของคุณ / Your task

You receive **one file**: `annotate_<yourid>.html`. Open it in any browser (double-click;
nothing installs, nothing uploads). For **176 items** you give:

- **บทร้อยกรอง (poems, 132 ข้อ)**: rate **2 axes** (Topicality, Coherence) 1–5, and mark each
  **meter dimension** ✓ ถูก / ✗ ผิด.
- **คู่คำสัมผัส (rhyme pairs, 44 ข้อ)**: one judgment: คำสองคำนี้ **สัมผัสสระ** กันหรือไม่.

Work autosaves; you may close and resume anytime. When done, click **Export** → it downloads
`labels_<yourid>.json` → **send that one file back**.

---

## 2. การใช้เครื่องมือ / Using the tool

1. เปิดไฟล์ `annotate_<yourid>.html` → กด **Begin**.
2. แต่ละข้อ: กด **1–5** (คีย์ลัด) ให้แกนที่ไฮไลต์ (topicality ก่อน แล้วเลื่อนไป coherence อัตโนมัติ);
   กด ✓/✗ ของแต่ละมิติฉันทลักษณ์; ใส่หมายเหตุได้ถ้าต้องการ.
3. `←` `→` เลื่อนข้อ. แถบความคืบหน้าด้านบนบอกว่าเหลือกี่ข้อ.
4. กด **Rubric** ในแถบบนเพื่อดูเกณฑ์ย่อได้ตลอดเวลา.
5. เสร็จแล้วกด **Export labels** → ส่งไฟล์ `labels_<yourid>.json` กลับ.

---

## 3. รอบฝึก / Training round (กรณีมีผู้ประเมินมากกว่าหนึ่งคน)

ก่อนประเมินอิสระ ให้ผู้ประเมินทุกคน **ประเมินข้อแรก ๆ ~10 ข้อพร้อมกัน** แล้วเทียบผล
ถ้าต่างกันให้คุยจนเข้าใจเกณฑ์ตรงกัน. จากนั้นจึง **แยกกันประเมินที่เหลือโดยไม่ปรึกษากัน**.
ขั้นนี้สำคัญที่สุดในการทำให้ค่าความสอดคล้อง (α) สูงพอ.

---

## 4. แกนความหมาย / Coherence axes (1–5)

> เกณฑ์นี้ตรงกับที่เครื่อง LLM-judge ใช้ทุกตัวอักษร (เพื่อวัดว่าเครื่องตัดสินตรงกับคนแค่ไหน).

**TOPICALITY — บทกวีพูดถึงหัวข้อที่กำหนดหรือไม่?**
- **1** = นอกเรื่อง / ไม่เกี่ยวกับหัวข้อ
- **3** = หัวข้อปรากฏแค่แวบเดียว (passing mention)
- **5** = บทกวีพูดถึงหัวข้อนั้นอย่างเป็นเนื้อเป็นหนัง

**COHERENCE — ประโยคไทยอ่านรู้เรื่อง และบรรทัดต่าง ๆ เชื่อมโยงกันหรือไม่?**
- **1** = คำสุ่มไม่เป็นประโยค (เช่น คำเดียวซ้ำ ๆ)
- **3** = แต่ละวรรคถูกไวยากรณ์ แต่ไม่เชื่อมโยงกัน (disjointed)
- **5** = เชื่อมโยงสมบูรณ์ ทุกวรรคต่อเนื่องเป็นเรื่องเดียว

**ข้อห้ามสำคัญ (HARD CONSTRAINTS):**
- **อย่า**ประเมินจำนวนคำ / เอก-โท / ครุ-ลหุ / สัมผัส ในสองแกนนี้ — นั่นเป็นหน้าที่ของแถวมิติฉันทลักษณ์.
- **อย่า**หักคะแนนเพราะใช้คำเก่า/คำวรรณคดี/คำหายาก — กวีคลาสสิกใช้คำเหล่านี้เป็นปกติ.
- ตัดสิน **เฉพาะเนื้อหา** (หัวข้อ + ความเชื่อมโยง) เท่านั้น.

---

## 5. มิติฉันทลักษณ์ / Meter dimensions (✓ ถูก / ✗ ผิด)

ตัดสิน **ทีละมิติอย่างอิสระ** สำหรับทั้งบท: บทหนึ่งอาจจำนวนคำถูก (✓) แต่สัมผัสผิด (✗) ได้.
แต่ละบทจะแสดงเฉพาะมิติที่เมตรนั้น **บังคับ** (ดูแผนผังเต็มใน `meter-specs.md`):

| มิติ | ✓ เมื่อ | ✗ เมื่อ | บังคับในเมตร |
|---|---|---|---|
| **count** (จำนวนคำ) | ทุกวรรคมีจำนวนพยางค์ครบตามแผนผัง | มีวรรคใดวรรคหนึ่งเกิน/ขาด | ทุกเมตร |
| **tone** (เอก-โท) | ตำแหน่งบังคับเอก/โท ลงไม้ถูกครบ | ตำแหน่งบังคับใดขาดไม้/ผิดไม้ | โคลงสี่สุภาพ |
| **rhyme** (สัมผัส) | สัมผัสบังคับทุกตำแหน่งเชื่อมถูก (**ตัดสินด้วยเสียง**) | สัมผัสบังคับใดไม่รับกัน | ทุกเมตร |
| **kru_lahu** (ครุ-ลหุ) | เสียงหนัก-เบา ตรงแผนผัง `ค-ค-ล-ค-ค \| ล-ล-ค-ล-ค-ค` | ตำแหน่งใดผิดครุ/ลหุ | อินทรวิเชียรฉันท์ ๑๑ |

**ตัวอย่าง (worked examples):**
- **count ✗**: กาพย์ยานี ๑๑ วรรคแรกบังคับ 5 คำ แต่แต่งมา 6 คำ (`ดอก ไม้ ผลิ บาน สะ พรั่ง`) → count = ✗.
- **tone ✓/✗**: โคลงสี่สุภาพ บาท ๑ คำ ๔ บังคับ **เอก**: "เธอจาก**ไป่**แล้วไกล" (มีเอก) = ✓;
  ถ้าเขียน "เธอจาก**ไป**แล้วไกล" (ไม่มีเอกในตำแหน่งบังคับ) = ✗.
- **rhyme ✓**: ตัดสินด้วยเสียงไม่ใช่ตัวสะกด: `ศักดิ์` รับ `รัก` ได้ (การันต์เงียบ) = สัมผัสถูก.
- **kru_lahu ✗**: ฉันท์ ตำแหน่งที่บังคับ **ลหุ** (เสียงเบา) แต่ใช้คำครุ เช่น "มา" = ✗.

ถ้าไม่แน่ใจมิติไหน ให้เลือกตามที่มั่นใจที่สุด แล้วพิมพ์เหตุผลสั้น ๆ ในช่องหมายเหตุ.

---

## 6. คู่คำสัมผัส / Rhyme pairs (✓ สัมผัส / ✗ ไม่สัมผัส)

แต่ละข้อแสดงคำสองคำ. ตอบว่าทั้งสอง **สัมผัสสระ** กันหรือไม่ คือมี **เสียงสระและตัวสะกดท้ายเหมือนกัน**.

**ตัดสินด้วยเสียงที่ออก ไม่ใช่ตัวสะกดที่เขียน:**
- `ศักดิ์` ~ `รัก` → ✓ (ตัวการันต์ ์ เงียบ เสียงคือ /รัก/)
- `หนา` ~ `นา` → ✓ (ห นำ เงียบ เสียงคือ /นา/)
- `ใจ` ~ `ดี` → ✗ (คนละสระ)
- `ทอง` ~ `เย็น` → ✗ (คนละสระและตัวสะกด)

อย่ากังวลเรื่องวรรณยุกต์ (เสียงสูง-ต่ำ): สัมผัสสระสนใจ **สระ + ตัวสะกด** เป็นหลัก.

---

## 7. หลังประเมินเสร็จ / After labeling

1. ส่งไฟล์ `labels_<id>.json` กลับ.
2. ทีมนำผลการประเมินไปตรวจความถูกต้องของเครื่องตรวจฉันทลักษณ์ และเลือก LLM-judge ที่ตรงกับคนที่สุด.
3. กรณีมีผู้ประเมินสองคน: ทีมคำนวณ **ค่าความสอดคล้อง (Krippendorff α)** จากผลอิสระของทั้งสองคน (เพดานความน่าเชื่อถือ)
   แล้วผู้ประเมิน **มาคุยข้อที่ต่างกัน** ให้ได้ข้อสรุปร่วม (consensus) → เป็น **gold**.

> หลักการ: **ประเมินโดยอิสระ** (ความเห็นอิสระคือสิ่งที่เราวัด).
> ประเมิน "เท่าที่เห็นในบท": ถ้าบทพิมพ์มาเท่านี้ก็ตัดสินเท่านี้ ไม่ต้องเดาว่ากวีตั้งใจอะไร.
